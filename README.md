# 哄我上班 😽（VS Code 扩展）

> ⚠️ 当前为中文界面（i18n 尚未落地，`package.nls.json` 已预留占位）。

一个住在你编辑器状态栏里的实时薪资时钟。设置好月薪和上下班时间，然后盯着状态栏上的数字不断跳动——每一秒，你都在变得更富有一点。

> 「不是我选择上班，是钱选择了我。」

## 功能

- **状态栏实时薪资** — 精确到小数点后多位（可配置 0–6 位），看着每一秒的钱到账
- **双计算模式**
  - 🏢 **上班才赚钱** — 只在工作时段累计薪资，非工作时间显示 💤
  - 🌙 **随时都赚钱** — 月薪平摊到整月的每一秒，睡觉也在赚
- **悬浮进度面板** — 鼠标悬停状态栏，查看今日 / 本周 / 本月工作进度条与已赚金额
- **法定节假日与调休** — 内置 2024–2026 年中国法定节假日与调休数据，支持添加 / 删除自定义调休上班日，也可一键关闭调休（适合外企 / 弹性工作制）
- **节假日数据过期提醒** — 当前年份超出内置数据覆盖范围时自动弹出警告

## 使用

1. 在 VS Code 扩展视图中安装本扩展（或 `vsce package` 后安装生成的 `.vsix`）
2. 状态栏右侧出现 💰 金额即表示已生效
3. 点击状态栏图标打开设置，填写月薪、上下班时间和午休时长

## 命令

| 命令 | 说明 |
| --- | --- |
| `薪资时钟: 打开扩展设置` | 跳转到扩展设置页（点击状态栏图标同效） |
| `薪资时钟: 切换状态栏显示` | 显示 / 隐藏状态栏薪资 |
| `薪资时钟: 添加调休` | 交互式添加自定义调休上班日 |
| `薪资时钟: 删除调休` | 交互式删除已添加的调休 |
| `薪资时钟: 输出调试信息` | 在输出面板打印当前计算明细 |

## 开发

```bash
npm install
npm run compile   # 编译到 out/
npm run watch     # 监听编译
npm test          # 运行单元测试
npm run lint      # ESLint
```

技术栈：TypeScript + VS Code Extension API，零运行时依赖。
